# Dhaatri One Gram Jewellery
1. `npm install` then `npm run dev` – the site works immediately with sample products.
2. Edit shop details (phone, address, Instagram, hours) in `src/config.js`.
3. Supabase: create a project → run `supabase.sql` in the SQL editor → add the owner under Authentication → Users.
4. Copy `.env.example` to `.env` and fill the 3 values (WhatsApp number format: 919876543210).
5. Open `/#/admin`, log in, add products with photos. Real products replace the samples automatically.
Hero/About photos: edit the `<img src>` in `Hero.jsx` / `About.jsx` (put files in `/public`).
